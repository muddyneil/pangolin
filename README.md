# Pangolin

Pangolin is a GitHub Actions subscription generator. Configuration and generated output live in the repository root:

```text
config.yaml  # subscription sources maintained in Git
clash.yaml   # generated by the manual deployment workflow
```

## Configure sources

Edit the committed [`config.yaml`](config.yaml) and add one or more HTTP/HTTPS subscription sources. `mihomo` is deliberately not configured here: the workflows download the current Linux AMD64 Mihomo release from the official [MetaCubeX/mihomo](https://github.com/MetaCubeX/mihomo) GitHub repository.

```yaml
sources:
  - name: "example"
    primary: "https://example.com/clash.yaml"
    fallbacks: []
```

## GitHub Actions

- **CI** runs on each push and pull request: `go vet`, `go test`, and a Linux AMD64 binary build. The binary is retained as a workflow artifact.
- **Deploy subscription** is started manually from the Actions page. It downloads Mihomo, produces the root `clash.yaml`, and deploys that file to GitHub Pages. Enable GitHub Pages with source **GitHub Actions** in the repository settings before the first deployment.

The deployed subscription is available at:

```text
https://<owner>.github.io/<repository>/clash.yaml
```

For a local Ubuntu run, first place the official core at `tools/mihomo/mihomo` and make it executable, then run:

```sh
go run ./cmd/pangolin
```

Use `--config path/to/config.yaml` only to test an alternate source configuration. The default is the repository-root `config.yaml`.
